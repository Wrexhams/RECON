# recon.py — OSINT Suite for Termux A single-file CLI tool for gathering Open Source Intelligence (OSINT) on IP addresses, domains, email addresses, phone numbers, and usernames. It runs directly on Android via Termux. > ⚠️ Intended solely for self-OSINT, auditing your own infrastructure, and authorized penetration testing. Using this tool against third parties without their consent is illegal (violates Article 137 of the Criminal Code of the Russian Federation and equivalent laws in other jurisdictions). ## Features | Module | Functionality | |---|---| | **IP lookup** | Geo-location, ASN, time zone, VirusTotal, AbuseIPDB, Shodan (ports + CVEs) | | **Reverse DNS** | PTR records + shared hosts via HackerTarget | | **Subdomain enum** | crt.sh (CT logs) + HackerTarget | | **Phone lookup** | Country, carrier, line type, time zones (offline, using the `phonenumbers` library) | | **Username lookup** | Checks 20+ platforms simultaneously + retrieves GitHub API details | | **Email lookup** | LeakCheck, Hunter verification, MX records | | **Domain lookup** | WHOIS, HTTP headers, robots.txt, VirusTotal, Hunter (email discovery) | | **Batch mode** | Processes a JSON list of targets → generates an HTML report | Results are saved to `~/recon_out/` in JSON format, with an optional HTML report. ## Installation ```bash pkg install python git -y git clone https://github.com/<your-username>/recon.git cd recon python recon.py
